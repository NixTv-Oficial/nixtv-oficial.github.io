Autenticação segura via GitHub. Nenhum token pessoal é necessário.

Use um token pessoal de acesso refinado (fine-grained) do GitHub com permissão Contents: Read and write somente neste repositório. O token fica apenas na memória desta aba, não é salvo no site nem no navegador. Esta página é pública; a autorização para publicar é verificada pelo GitHub.
